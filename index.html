Proyecto destacado · IA

finanzas-agent

Agente con Claude que gestiona finanzas personales en lenguaje natural a través de un servidor MCP (Model Context Protocol) propio.

  • Human-in-the-loop: las acciones destructivas nunca se ejecutan sin aprobación explícita.
  • Defensa contra prompt injection: la salida de las herramientas se trata como datos, con un eval específico.
  • Evals automatizados que verifican el estado final de la base de datos con SQL.
  • CI en dos señales: tests deterministas en cada push; evals con costo solo cuando cambia el agente.
  • Observabilidad: trazas de latencia, tokens y costo por tarea.
  • Python
  • MCP
  • Claude API
  • Pydantic
  • SQLite
  • pytest
  • GitHub Actions
  • Docker

02 — Enfoque

Cómo trabajo

01

Seguridad desde el diseño

Validación en cliente y servidor, prevención de XSS y de prompt injection, y aprobación humana para acciones sensibles.

02

Código mantenible

Separación por capas, componentes reutilizables y lógica de negocio cerca de los datos que protege.

03

Calidad medible

Tests, evals, linters e integración continua. Si un cambio importa, se mide.

04

Accesible por defecto

HTML semántico, atributos ARIA, contraste y SEO como parte de la definición de terminado.
